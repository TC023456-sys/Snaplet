# Snaplet

独立的 macOS 截图与标注项目，基于 [sw33tLie/macshot v4.3.0](https://github.com/sw33tLie/macshot/tree/v4.3.0)（GPL-3.0），由 TC023456-sys 维护修改版。非上游官方发布。

本仓库仅包含 Snaplet 源码修改、品牌资源、键盘修复、测试及构建流程，不包含 Retina Dummy 项目。

## 下载与构建

当前发布版本为 **4.3.0-finder.52**，安装包见 [Releases](https://github.com/TC023456-sys/Snaplet/releases)，版本变更见 `macshot-finder/RELEASE-NOTES.md`。草稿和本地修改不等于公开更新。

构建说明见 `macshot-finder/README.md`，自动步骤见 `.github/workflows/macshot-finder.yml`。流程克隆固定上游、应用补丁、替换品牌资源、执行测试并构建安装包及完整对应源码。原作者署名与 GPL 声明保留。

设置采用原生 AppKit 侧栏和简洁分组，支持浅深色及高级选项，不使用 WebView 包装预览。

更新服务只读取 `TC023456-sys/Snaplet`。旧包文件名、标签前缀及应用标识为兼容更新和现有设置而保留。临时签名版本更新后可能需要重新授予录屏权限；源码测试不代替安装后的权限验证。

## 更新后必须重新关联权限（临时签名版本）

此安装包使用临时签名（ad-hoc），更新后的程序身份可能与系统保存的旧授权不匹配。**即使系统开关显示已开启，截图或窗口切换仍可能不可用；只关闭再打开开关可能无效。**

安装新版后，请按以下步骤重新关联：

1. 退出 Snaplet，把新版 `Snaplet.app` 放到 `/Applications`（“应用程序”），替换旧版，避免运行下载目录中的另一份。
2. 打开“系统设置 → 隐私与安全性 → 辅助功能”，选中旧 Snaplet，点击“−”删除条目。
3. 点击“＋”，从“应用程序”重新添加当前 `Snaplet.app`，开启开关。辅助功能用于窗口切换和快捷键相关操作。
4. 在“录屏与系统录音”（部分系统称“屏幕录制”）重复上述“删除旧条目 → 添加当前版 → 开启”的步骤。录屏权限用于截图、录制和窗口预览。
5. 如果系统要求管理员确认，请在系统弹窗亲自输入密码；按提示选择“退出并重新打开”。然后分别检查截图和窗口切换。

每次更换临时签名构建后都建议按此流程重新关联；不同 macOS 版本是否保留旧授权并不一致。不需要重置全部应用权限，不要删除其他软件的授权，也不要关闭系统安全保护。麦克风、摄像头仅在使用相应录制功能时按需授权。
